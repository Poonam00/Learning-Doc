# Behavioral Properties of Claude
1. Responses vary each time
2. Confident tone is not a sign of accuracy
3. Context is a budget
4. Knowledge has a training boundary
5. Configured workflows/procedures reduces output variance but does not eliminate it

# Entry Point of Calude
1. Chat: task starts and end within the session. Good for one-off question. Single use
2. Project: Recurring work. Same knowledgeable each time
3. Artifact: Creates standalone content that show up in separate panel next to chat like diagram, document, slide, spreadsheet etc 
4. Research: available of paid plan. For deep analysis

# Capability Layer
- Entry points determine where you work. The capability layer determines what Claude can do within that entry point.
- The Four Layer Model:
  1. Project:  backdrop knowledge as a context
  2. Skill: defining workflow that handles repeated task
  3. Code Execution: it should verify the computation to cause consistent output
  4. Memory: relevant information carry forward across sessions
- Each layer is independent. We can used any combination to get our work done.
- SKILL: skills are reusable procedures. Built-in skill are also available. Lives at account level. For example: workflow for editing spreadsheet, word doc etc. Skill are used for repeatative task but each time it can produce varied result.
- CODE EXECUTION: Code Execution is Claude's sandboxed computation environment. It could be provided by your partnered company as well. For the task where code-execution/computation is required, Claude up the sandbox and execute the code and return output. For example: any numeric calculation, output is some file, output is chart or diagram.
- MEMORY: memory retains work related facts across sessions. Memory not reviewed frequently can be misleading so it's important to curate it on regular basis. Incognito mode keeps session out of memory and chat history.

# Conversation Hygiene
- each Claude conversation has finite working-memory limit. After this limit, the conversation is summarized and the old conversation is there in the history for reference but not in memory. Sometime when we chat for long duration, the Claude forget the initial instructions because of this
- measures to take when this happens:
  1. RESTART a new conversation
  2. SUMMARIZE current conversation and paste in new chat
  3. PERSIST the information that can be used in further session in the memory or the knowledge base
- Memory Curation: Memory serves best when curated. Try to keep the memory upto-date.
- Usage Limit: follow the above measures to stay within the limit, otherwise the task will remain incomplete.
