Java Virtual Machine(JVM) is part of Java Runtime Environment(JRE). JVM is where the compiled byte code executes(runs). JVM sometimes contains a Just in time compiler(JIT) whose job is to convert byte code to native machine code
*JIT is a part of JVM to improve the speed of JVM to execute code
*JVM converts source code to byte code whereas JIT convert bytecode to machine code
*JIT is a combination of interpretter and compiler
*First it act as interpretter,While interpretting each line of code,it come across hot code(code which is called again and again) and monitors it,as soon it reaches its threshold point ,it compiles the same piece of code rather than interpretting again and again
