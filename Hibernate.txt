3)Caching
->
1st level caching->linked with session
2nd level caching->linked with session factory
Query caching->linked with parameter in query

4)session is thread unsafe but session factory is thread safe


SessionFactory:
They are thread safe.It is created during application startup. One SessionFactory is used for one database using a configuration file. If multiple databases connections are required we need to create multiple session factory
it has a optional 2nd level of caching with the sessionFactory

Session:
Used to get a physical conncetion with a database.It is instantiated each time a connection is needed
Session provide 1st level of caching which is by default in hibernate

transient:
object which is not associated with a session

persistent:
object associated with session and its representation/schema is present in the database. 
Persistent object should have a no-arg constructor for Reflection and proxies
should have a unique id
all fields shoud be marked private and have getter and setters



detached:
Once the session is closed the persistent objects become detached.
